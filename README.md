# GitHub Practice

Git과 GitHub의 기본 사용법을 연습하기 위한 Repository입니다.

## 실습 목표

* Repository Clone
* Branch 생성
* 파일 수정
* Commit
* Push
* Pull Request 생성
* Merge
* Pull

## 실습 규칙

1. `main` 브랜치에서 직접 수정하지 않습니다.
2. 자신의 Branch를 생성해서 작업합니다.
3. 작업 후 Commit과 Push를 진행합니다.
4. GitHub에서 Pull Request를 생성합니다.
5. Pull Request를 확인한 뒤 `main` 브랜치에 Merge합니다.
